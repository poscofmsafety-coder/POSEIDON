## V6.2 작업중지권 알림 설정

작업중지권은 외부 서비스 설정 없이도 관리자 대시보드와 이벤트 센터에 즉시 접수됩니다.

선택적으로 이메일/문자/Webhook을 연결할 수 있습니다.

### 이메일
Cloudflare Secret:
- `RESEND_API_KEY`

환경값:
- `ADMIN_EMAIL`
- `EMAIL_FROM`

### 문자
Cloudflare Secret:
- `TWILIO_ACCOUNT_SID`
- `TWILIO_AUTH_TOKEN`

환경값:
- `TWILIO_FROM_NUMBER`
- `ADMIN_PHONE`

### Webhook
- `NOTIFY_WEBHOOK_URL`

운영에서는 API Key/Token을 GitHub에 커밋하지 말고 Cloudflare Secret으로 등록하세요.

## V6.9 Smart MSDS

관리자는 `스마트 MSDS` 탭에서 물질안전보건자료 PDF를 등록·삭제할 수 있고, 관리자와 현장 사용자는 등록된 자료를 검색해 포세이돈 내부 PDF 뷰어에서 바로 확인할 수 있습니다. PDF는 D1에 작은 청크로 분할 저장하며 파일당 최대 12MB, MSDS 자료 권장 합계 150MB를 적용합니다. 대량 운영 시 Cloudflare R2 등 별도 문서 저장소로 전환하는 것을 권장합니다.


## V6.10 Smart MSDS PDF 업로드 호환성

일부 정상 PDF가 파일 첫 바이트에 `%PDF-`가 바로 나오지 않아 업로드가 거부되는 문제를 보완했습니다. 포세이돈은 파일 앞부분 4096바이트 범위에서 PDF 헤더를 확인하고, 브라우저 MIME이 `application/octet-stream`으로 전달되는 환경도 실제 PDF 헤더가 확인되면 등록합니다.


## V6.11 긴급대응 / D-안전회의 / 개인정보 보호

- 119 신고 탭의 전화 버튼은 모바일 전화 앱을 여는 방식이며, GPS는 POSEIDON 관리자 이벤트로 전송되고 전화 통화에 자동 전달되지는 않습니다.
- 비상연락망은 관리자 화면에서 병원/노동부/관리자 등 실제 운영 연락처를 등록하세요. 기본값은 119만 제공합니다.
- D-안전회의는 Excel 행 복사/붙여넣기 후 소통보드로 변환·저장하며, 종사자는 소속/이름/내용으로 의견을 남길 수 있습니다.
- 얼굴 비식별화는 작업자 ROI가 확보된 프레임을 모자이크하며, 정확한 비식별화가 중요한 경우 별도 개인정보 보호 검증이 필요합니다.
