# POSEIDON PPE 전용모델 학습 가이드

## 왜 CHECK가 나오는가
현재 범용 PPE 모델이 보안경/마스크의 착용 또는 미착용을 충분한 신뢰도로 직접 검출하지 못하면 POSEIDON은 추정 대신 CHECK를 표시합니다.

## 권장 학습 구조
안전모/보안경/마스크는 작업자 크롭을 기준으로 각 항목의 착용 여부를 분류하는 전용 모델을 만드는 것이 좋습니다. 운영 중 모델이 스스로 바로 학습하지 않고, 사람이 정답을 확인한 데이터만 모아서 별도로 재학습합니다.

1. 현장 지킴이의 AI 학습 피드백에서 작업자를 선택합니다.
2. 안전모/보안경/마스크의 실제 상태를 착용/미착용/판정불가로 지정합니다.
3. 현재 작업자 장면 학습데이터로 저장을 누릅니다.
4. 최소 500건부터 시작하되 각 상태가 균형 있게 포함되도록 수집합니다. 실제 목표는 다양한 거리/각도/조명/작업복을 포함한 2,000건 이상입니다.
5. 관리자 로그인 상태에서 `/api/training/export`를 열어 라벨 메타데이터 JSON을 내려받을 수 있습니다. 이미지 주소는 각 row의 `image_url`입니다.
6. 모델은 별도 Colab/GPU 환경에서 재학습하고 검증셋 성능을 확인한 뒤 ONNX로 내보냅니다.
7. Cloudflare `PPE_MODEL_URL`을 새 ONNX 모델 URL로 변경하면 브라우저가 새 모델을 사용하도록 배포할 수 있습니다.

## 데이터 원칙
- 동일인이 같은 자리에서 찍힌 비슷한 프레임만 많이 모으지 않습니다.
- 착용/미착용을 균형 있게 모읍니다.
- 정면, 측면, 원거리, 저조도, 일부 가림을 포함합니다.
- CHECK와 오탐/미탐 장면을 우선 수집합니다.
- 사람이 정답을 확인하지 않은 데이터는 학습 정답으로 사용하지 않습니다.

## 모델 교체
현재 Worker는 `PPE_MODEL_URL` 환경변수의 ONNX를 `/models/ppe.onnx`로 프록시합니다. 새 모델의 출력 클래스/형식이 기존 모델과 같으면 URL 교체만으로 사용할 수 있습니다. 출력 구조가 다르면 `public/ppe-worker.js`의 후처리도 함께 맞춰야 합니다.
