# POSEIDON V6.0 업그레이드

## 적용 사항

1. 사람 감지를 기존 PPE 모델의 `Person` 결과에만 의존하지 않고 **YOLO11n COCO ONNX** 전용 worker로 분리했습니다. 기존 SafetyVision PPE 모델은 안전모/보안경/마스크 판정을 계속 담당합니다.
2. 스마트폰은 카메라와 마이크 권한을 분리했습니다. 마이크를 거부해도 카메라/AI 감지는 시작되며, 저장된 카메라 deviceId가 깨져도 후면카메라 → 기본카메라 순으로 자동 재시도합니다.
3. 스마트폰에서는 Worker의 OffscreenCanvas 호환성 문제를 줄이기 위해 메인 화면에서 640x640 RGBA 프레임을 만든 뒤 worker로 전달하는 fallback 경로를 추가했습니다. 저사양 모바일은 사람/PPE 추론 주기를 자동으로 낮춥니다.
4. 이벤트 센터에 개별 삭제, 전체 삭제, 보관기간 설정, 지금 정리 기능을 추가했습니다. 기본 30일 보관이며 매일 03:00 KST(18:00 UTC)에 자동 정리합니다. 이벤트 스냅숏도 함께 지워지고 학습데이터는 유지됩니다.
5. Google Colab T4용 notebook을 포함했습니다. YOLO11n ONNX export, Kaggle API 연결, 산업안전 PPE 데이터셋 다운로드, 클래스 감사, 재학습, ONNX export 순서입니다.

## 중요

- `YOLO11n` 기본 모델은 사람을 포함한 COCO 객체 탐지 모델입니다. 안전모/보안경/마스크는 기존 PPE 모델 또는 현장 맞춤 재학습 모델이 담당합니다.
- Kaggle 데이터셋마다 클래스 번호와 이름이 다릅니다. 여러 데이터셋의 YOLO 라벨 파일을 단순 복사해 섞으면 잘못 학습됩니다. 반드시 클래스 매핑 후 병합해야 합니다.
- 현재 기본 YOLO11n ONNX URL은 `webnn/yolo11n`의 공개 ONNX 아티팩트입니다. 운영/상용 배포 전 Ultralytics 및 데이터셋 라이선스를 별도로 검토하세요.
